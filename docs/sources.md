# Sources

Public references behind the rules in this repository. None of them is affiliated with this project; the rules here are a practitioner's distillation, not a summary of these works.

| Reference | What it informs here |
|---|---|
| [Federal plain language guidelines](https://www.plainlanguage.gov/guidelines/), plainlanguage.gov | `plain-language`: write for one specific reader, define terms at first use, short sentences, active voice, lead with the point |
| Nancy Duarte, *slide:ology* (2008) and *Resonate* (2010), [duarte.com](https://www.duarte.com/) | `slide-writing-rules` and `concise-slide`: one idea per slide, the slide as an argument rather than a document, breathing room between dense slides |
| Edward Tufte, *The Cognitive Style of PowerPoint* (2003), [edwardtufte.com](https://www.edwardtufte.com/) | `slide-writing-rules`: evidence over fragments, no decoration that hides the data, respect for the reader's intelligence |
| Barbara Minto, *The Pyramid Principle* | `slide-writing-rules` (Rule 9, the takeaway block) and `pm-communication`: state the conclusion first, then the support |
| [Linear Method: write issues, not user stories](https://linear.app/method/write-issues-not-user-stories) | `anti-slop` and `pm-communication`: plain task language, short texts, no ceremony in the wording |
| Colin Bryar and Bill Carr, *Working Backwards* (2021) | `pm-communication` and `deck-rebuild-blueprint`: the written narrative as the record of a decision, prepared before the meeting rather than improvised in it |
